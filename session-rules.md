# Правила учебной сессии

## Формат работы
1. Решаем **одну задачу за раз** в файле `script.js`.
2. В `script.js` находится ТОЛЬКО текущая задача: условие, пустая функция, тесты.
3. Решение пишет студент сам. Учитель даёт только заготовку и подсказки по запросу.

## Порядок сессии
1. Начинаем с простых (Easy) задач на повторение по разным темам.
2. Затем закрепляем Sliding Window парой средних (Medium) задач.
3. Потом переходим к новой теме.

## Переход к следующей задаче
- Когда студент пишет «далее» / «next» / «переходим дальше», учитель **полностью стирает** содержимое `script.js` и готовит следующую задачу.
- Каждая новая задача — новая заготовка, без старых решений.

## Заготовка задачи
Каждая задача в `script.js` содержит:
- Комментарий с номером и названием задачи;
- Комментарий с условием на русском;
- Пустая функция;
- Вспомогательные пустые функции (если нужны);
- Тестовые данные с `console.log`.

## Решение
- Учитель **НЕ пишет решение** в `script.js`.
- Подсказки выдаются пошагово — одна за раз.
- Подсказки даются только по запросу студента.
